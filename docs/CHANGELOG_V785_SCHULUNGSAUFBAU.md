# Changelog: Schulungsunterlagen v7.8.5 Runtime Packaging

- Bestehende v4.3.3- und v7.5-Schulungsinhalte erhalten.
- Hauptunterlagen um Kapitel zu Keim v7.8.5 ergänzt.
- Grundkurs um ein Anfänger-kompatibles Kapitel „Programme ausliefern statt nur ausführen“ ergänzt.
- Full Runtime Packager dokumentiert.
- Self-Bootstrapping Launcher für PE64/ELF64 als Schulungsthema ergänzt.
- GPU-aware Packaging mit Manifest, Smoke-Test und CPU-Fallback ergänzt.
- Runtime Value Model und Value-Tags dokumentiert.
- Packaging-Modi `full-runtime`, `native-subset`, `zipapp` und `directory-bundle` ergänzt.
- Projekt-Web-Overlay über `web/index.html` ergänzt.
- Neue Beispiele unter `examples/current/` ergänzt.
- Dozentenleitfäden, Migration und Site-Manifeste aktualisiert.
